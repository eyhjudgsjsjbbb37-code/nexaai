NexaAI - AI Landing Page Template
=================================

Thank you for purchasing NexaAI!

NexaAI is a modern, responsive landing page template designed for AI
startups, AI tools, SaaS products, technology companies, and digital
products.

---------------------------------
FEATURES
---------------------------------

- Modern AI-focused design
- Fully responsive
- Works on desktop, tablet, and mobile
- HTML5
- CSS3
- Easy to customize
- Lightweight and fast
- No frameworks required
- No installation required
- SEO-friendly structure
- Open Graph / Social Media Preview included

---------------------------------
FILES & FOLDERS
---------------------------------

index.html
Main landing page.

css/style.css
Main stylesheet containing the website design and layout.

public/og-image.png
Social media preview image used when sharing the website.

---------------------------------
HOW TO USE
---------------------------------

1. Open the NexaAI folder.
2. Double-click index.html.
3. The website will open in your browser.

No Node.js, npm, or other software is required to view the template.

---------------------------------
HOW TO CUSTOMIZE
---------------------------------

You can edit the website using any code editor such as Visual Studio Code.

To change the website content:
Open index.html and edit the text, headings, buttons, and sections.

To change colors, spacing, fonts, or other visual styles:
Open css/style.css.

---------------------------------
SOCIAL MEDIA PREVIEW
---------------------------------

The template includes Open Graph meta tags for social media sharing.

The preview image is located at:

public/og-image.png

If you publish the website on your own domain, update the
og:image and og:url values inside index.html to match your website URL.
